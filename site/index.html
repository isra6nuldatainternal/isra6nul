Behind the Camera

Photographs should feel like memory, not documentation.

Northlight was founded by Mara Voss on that belief. Every session starts the same way — an hour spent simply watching how the light moves through a room, a garden, a face — before a single frame is made.

The studio works with a small, close-knit second-shooter and retouching team, and takes on a deliberately limited number of weddings and campaigns each year so that every project gets the same unhurried attention.

— Mara
